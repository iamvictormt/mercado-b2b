# Componentes de página

Estes módulos contêm os componentes visuais interativos usados pelas rotas em `src/app`.
O roteamento, os metadados e a geração estática pertencem ao Next.js App Router e ficam em
`src/app`; esta separação permite manter as páginas interativas como Client Components sem
perder metadados renderizados no servidor.
